# Attribution and scope

Original project code is distributed under the MIT license in LICENSE.

MLX and MLX-LM are external dependencies developed by the MLX community. Model snapshots are downloaded separately from the pinned Hugging Face repositories in models.json; consult those model cards for their licenses and upstream attribution. No model weights are included here.

The research directory contains citations, attributed evidence excerpts and our analysis. Third-party text/code excerpts retain their original authorship and applicable terms; the project license does not relicense them. Downloaded full article/document bodies are not distributed in this repository.

Measurement manifests intentionally preserve the original machine-local model paths and source hashes. Those paths document the original run; use explicit --target and --draft paths on another machine.
